# Принятые решения

Их можно сменить, если практика упрётся. Пока новые куски кода им следуют.

## Стек

| Вопрос | Решение |
| --- | --- |
| Игра | Minecraft 1.20.1 |
| Загрузчик | Forge 47.4.28 |
| Java игры | 17. Подтягивается Gradle toolchain (foojay), системный JDK 21 для этого не обязателен |
| Маппинги | Parchment `2023.09.03-1.20.1` поверх официальных имён. Канал читаемых имён параметров, лицензия данных CC0 |
| Имя | Canopy, идентификатор `canopy` |
| Пакет | `io.github.krabek515.canopy` |
| Группа сборки | та же, что пакет |
| Версия мода | 0.1.0, пока нет играбельного среза |
| Лицензия нашего кода | All Rights Reserved, репозиторий приватный |
| Репозиторий | `Krabek515/JungleMod` |
| Язык игрока | `ru_ru` и `en_us` одновременно |
| Язык документов | русский |

Почему Forge, а не Fabric: так попросил автор, и на 1.20.1 у Forge по-прежнему много готовых примеров на capability, biome modifier и генерацию. Parchment выбран потому, что на официальных маппингах параметры методов безымянные, а почти все современные моды этой версии всё равно кладут Parchment.

Чужие библиотеки пока не подключены. TerraBlender не нужен, если мы целиком подменяем биомы верхнего мира датапаком мода. GeckoLib не нужен, пока хватает ванильной модели. Curios не нужен, пока одежда сидит в четырёх слотах брони. Если одно из этих «пока» сломается, библиотеку добавляем точечно и записываем сюда.

## Как хранить состояние игрока

Жажда, температура, сырость тела, силы, раны и открытые страницы дневника — capability игрока, с синхронизацией на клиент. Сырость стопки — данные на предмете, иначе сушка конкретного факела не работает.

Не плодить отдельные полоски без поведения. Силы существуют, потому что без них жара и чаща не мешают двигаться.

## Как менять ваниль

Порядок предпочтения:

1. Датапак мода: биомы, спавн, рецепты, лут, пресет мира.
2. События Forge: скорость ломки, урон, тик игрока, погода, еда.
3. Короткий mixin, если события нет. В комментарии одна строка, зачем он.

Пример: запрет комфортной копки — это `BreakSpeed` плюс накопление травмы руки, а не удаление блока из игры.

## Мир

Свой пресет мира, в котором верхний мир собран только из биомов мода. Нижний мир и Энд не используются: портал не ведёт в игру, измерение не часть прогресса. Ванильный hostile-спавн снимается модификатором биома глобально, а не надеждой на то, что в нашем биоме забыли прописать крипера.

Генерация гигантских деревьев и редких мест — свои configured feature и structure, когда до них дойдёт карта. В каркасе их ещё нет.

## Дневник

Прогресс знания — у игрока. Предмет книги только открывает экран и может быть мокрым. Так налёт и смерть не обнуляют изученное.

## Что сознательно не решено кодом

Баланс урона зверей, точные рецепты и список видов растений появятся вместе с первой играбельной фазой, а не в пустом репозитории. Направление уже лежит в [03-dizajn.md](03-dizajn.md).
