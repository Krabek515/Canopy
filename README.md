# Canopy

Мод на Minecraft 1.20.1 / Forge: выживание в мире, который состоит только из джунглей. Голод, жажда, температура и сырость вместо шахт и алмазной брони.

Репозиторий приватный. Замысел и правила лежат в [`docs/00-index.md`](docs/00-index.md). Если открываешь проект заново, начни оттуда.

## Стек

- Minecraft 1.20.1
- Forge 47.4.28
- Java 17 для игры (Gradle скачивает её сам)
- Parchment 2023.09.03-1.20.1

Идентификатор мода: `canopy`. Пакет: `io.github.krabek515.canopy`.

## Сборка

Нужны Git и JDK, которым можно запустить Gradle 8.8 (подойдёт 17 или 21). Отдельный JDK 17 ставить не обязательно.

В каталоге проекта:

```
.\gradlew.bat genIntellijRuns
.\gradlew.bat runClient
```

Первый запуск долго качает Minecraft, Forge и JDK 17. Клиент откроется с модом Canopy. В логе должна быть строка `Canopy common setup`.

Готовый jar: `.\gradlew.bat build`, файл в `build/libs`. В игру его кладут рядом с Forge 1.20.1 той же линейки 47.
