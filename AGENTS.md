# Canopy

Minecraft 1.20.1, Forge 47.4+, GeckoLib 4.8+. Аддон: пять кастомных биомов
подменяют ванильные джунгли, остальной мир не трогает.

- Идентификатор `canopy`, пакет `io.github.krabek515.canopy`.
- Текст для игрока на двух языках: `assets/canopy/lang/ru_ru.json` и `en_us.json`.
- Ассеты оригинальные, генерируются скриптами в `tools/art/` (Java, запускает
  обычный javac/java). Сторонние файлы не кладём; правила в `CREDITS.md`.
- Звуки — свои события в `assets/canopy/sounds.json`, ссылаются на ванильные
  сэмплы по имени с питчем.
- Биомы живут в `data/canopy/worldgen/biome/`; `CanopyBiomeSource` подменяет
  только климатические точки джунглей. Порядок фич строго ванильный, свои —
  в конец своих ступеней, иначе `Feature order cycle`.
- Дизайн-документы в `docs/` описывают историю проекта; финальная правда — код.
