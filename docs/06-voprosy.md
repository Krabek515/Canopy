# Закрытые вопросы

Ответы уже внесены в [01-zamysel.md](01-zamysel.md) и [04-resheniya.md](04-resheniya.md). Заново их не открывать, пока человек сам не передумает.

| Тема | Решение |
| --- | --- |
| Имя | Canopy, идентификатор `canopy` |
| Мистика | Редкие следы и странные мелочи. Не хоррор и не магия |
| Смерть | Обморок. Вещи остаются на любой сложности. На сложной игрока не уносят к точке возрождения |
| Кто игрок | Безымянный наблюдатель речной экспедиции |
| Море | Нет. Вода речная и болотная |
| Нижний мир и Энд | Закрыты. Прохождение — все достижения |
| Дневник | От первого лица, коротко, без хоррора. Русский основной, английский рядом |
